# السعودية خط أحمر — مدرسة شقصان للطفولة المبكرة

## الملفات
- `index.html`: صفحات وأقسام الموقع.
- `style.css`: التصميم المتجاوب.
- `app.js`: التفاعلات وحفظ بيانات العرض التجريبي.

## تشغيله محليًا
افتحي `index.html` في المتصفح. الأفضل استخدام استضافة ثابتة أو خادم محلي بسيط.

## النشر عبر GitHub Pages
1. أنشئي مستودعًا جديدًا على GitHub.
2. ارفعي الملفات الثلاثة إلى جذر المستودع.
3. من Settings → Pages اختاري النشر من فرع `main` ومجلد `/(root)`.
4. انتظري ظهور رابط الموقع.

## تنبيه مهم عن التخزين
هذه النسخة تحفظ البيانات باستخدام `localStorage` على الجهاز والمتصفح نفسه فقط. لا تُعد تخزينًا سحابيًا ولا تسمح بمشاركة البيانات بين الزائرات. لوحة المراجعة تجريبية وغير محمية بتسجيل دخول، لذلك لا تستخدميها للبيانات الحقيقية قبل ربط قاعدة بيانات وخدمة رفع ملفات مع صلاحيات إدارية آمنة. يمكن لاحقًا ربط الواجهة بخدمة مثل Firebase أو Supabase، مع قواعد وصول مناسبة.
