# موقع السعودية خط أحمر — متعدد الصفحات

## الصفحات
- `index.html`: شاشة البداية؛ لا يدخل الزائر إلى المبادرة إلا بالضغط على ختم «عهد الوطن».
- `home.html`: الصفحة الرئيسية وروابط الأقسام.
- `pledge.html`: وثيقة العهد.
- `rumors.html`: أصد الشائعات.
- `share.html`: إرسال رسالة وصورة.
- `wall.html`: جدارية الوطن.
- `certificate.html`: وثيقتي المختومة.
- `admin.html`: لوحة مراجعة تجريبية.

## رفعه إلى GitHub Pages
ارفعي كل ملفات هذه الحزمة إلى جذر مستودع GitHub. ثم Settings → Pages → Deploy from a branch → main → /(root) → Save. رابط الموقع يبدأ من `index.html`.

## تنبيه
الحفظ الحالي محلي على المتصفح والجهاز فقط، وليس تخزينًا سحابيًا. لوحة الإدارة تجريبية وغير محمية. لا تجمعي بيانات حقيقية قبل ربط قاعدة بيانات سحابية وإعداد تسجيل دخول وقواعد وصول آمنة.
