# السعودية خط أحمر — نسخة مهيأة لربط Firebase

هذه الحزمة معدّلة للاتصال بمشروع Firebase `saudi-redline-655ad` الذي زوّدتِنا بإعداداته.

**قبل رفعها للاستخدام الحقيقي، اتبعي ملف `SETUP_AR.md` كاملًا.** يلزم ضبط بريد المسؤولة في `firebase-config.js` وملفي القواعد، وتفعيل تسجيل الدخول، وإنشاء حساب المسؤولة، وإعداد Firebase Storage. لا تفتحي قواعد Firestore للكتابة العامة بلا قيود.

الصفحات: index.html, home.html, pledge.html, rumors.html, share.html, wall.html, certificate.html, admin.html.
